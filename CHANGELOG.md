# Changelog

## v0.1.0 – Initial public release candidate

- Flowing animated rainbow shader scoped to Spyro's player model.
- Adjustable rainbow animation speed, stripe density, and strength.
- Visual-only changes with no added abilities or cheats.
- First version confirmed working in a stream by creator dragxnflare.

This release candidate is based on the creator's original working v0.1.0 ZIP.
The original `mod.toml`, `shaders/rainbow.frag`, and `src/rainbow.c` files are preserved byte-for-byte.

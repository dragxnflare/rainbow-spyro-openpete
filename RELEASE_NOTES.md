# Rainbow Spyro v0.1.0 🌈🐉

**The first public release candidate of Rainbow Spyro!**

Made by **dragxnflare** with development assistance from **ChatGPT (OpenAI)**.

Rainbow Spyro adds smooth, animated RGB rainbow bands that flow across Spyro in the original *Spyro the Dragon (1998)* running through the OpenPete PC port. It is a **visual-only** mod; gameplay stays original.

**Features:** Adjustable rainbow speed, stripe density, and strength; shader applied to Spyro's player model; no cheats or new abilities.

**How to install:** Download **`rainbow-spyro-v0.1.0.zip`** under **Assets** below. Do not unzip. Put it in the `mods` directory beside `openpete-spyro1.exe`, launch the game, press **M → Mods**, and enable **Rainbow Spyro (Animated RGB)**.

**Requirements:** OpenPete with Spyro 1 game files and working mod/SDK support. Tested by the creator in OpenPete; not yet independently verified on other setups. This package does not contain any original Spyro game data.
